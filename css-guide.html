CSS beginner's guide

Learn CSS

CSS controls how webpages look and fit different screens. Learn the basics, then experiment with the examples.

In this guide, developers will learn about;

  • Selectors
  • Cascade and specificity
  • Colors and units
  • The box model
  • Text and fonts
  • Display and spacing
  • Flexbox
  • Grid

  • Pseudo-classes and focus
  • CSS variables
  • Debugging and practice

1. What CSS does

CSS stands for Cascading Style Sheets. HTML describes the content and structure of a page; CSS describes how that content is presented, including colors, spacing, and layout.

A CSS rule has a selector and a declaration block. Each declaration is a property and a value:

p {
  color: navy;
  font-size: 18px;
}

Here, p is the selector. The declarations set the paragraph's text color and size.

2. Add CSS to a page

The usual approach is to put CSS in a separate .css file and link it from the document's <head>.

<link rel="stylesheet" href="style.css">

For a quick experiment, you can also write rules inside a <style> element in the head. Keeping styles in a separate file makes them easier to reuse and maintain.

3. Select elements to style

Selectors choose which HTML elements a rule affects. Element selectors match tags, class selectors start with a dot, and ID selectors start with a hash.

h1 {
  color: darkslateblue;
}

.notice {
  background-color: lightyellow;
}

#page-title {
  text-align: center;
}

Use classes when a style should apply to multiple elements. An ID should identify one unique element on a page.

4. The cascade and specificity

When multiple CSS rules match an element, the browser resolves conflicts using the cascade. More specific selectors generally win over less specific ones; if specificity is equal, the later rule wins.

p { color: steelblue; }
.warning { color: firebrick; }

A paragraph with class="warning" will use the class rule's color. Prefer clear selectors and avoid relying on !important to resolve conflicts.

5. Colors and units

CSS supports named colors, hexadecimal colors, and functions such as rgb(). Pick the format that makes your styles easiest to understand.

body {
  color: #222222;
  background-color: rgb(245, 247, 250);
}

.badge {
  border: 2px solid darkorange;
}

Common size units include px for fixed lengths, rem for a size relative to the root font size, and % for a size relative to a containing element. Relative units can help layouts adapt.

6. Understand the box model

Each element is laid out as a box: content is surrounded by padding, a border, and margin. Padding is inside the border; margin creates space outside it.

* {
  box-sizing: border-box;
}

.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #52606d;
  margin: 16px;
}

border-box includes padding and border in the declared width, which makes sizing more predictable.

7. Style text

Typography rules can set the font, size, weight, line spacing, and alignment. A readable line height and text size make content more comfortable to read.

body {
  font-family: Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}

h1 {
  font-weight: 700;
  letter-spacing: 0.02em;
}

8. Display and spacing

The display property changes how an element participates in layout. Block elements usually start on a new line; inline elements flow with text. Flexbox and Grid are useful tools for arranging groups of elements.

.page {
  max-width: 900px;
  margin: 0 auto;
  padding: 24px;
}

.hidden {
  display: none;
}

Use padding for space inside a component and margin for space around it. A centered fixed-width page can use automatic left and right margins.

9. Arrange items with Flexbox

Flexbox is useful for arranging items in one direction, either a row or a column. Set display: flex on the parent container.

.navigation {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}

justify-content distributes items along the main axis, while align-items aligns them across the other axis.

10. Build layouts with Grid

CSS Grid is designed for layouts with rows and columns. Define the columns on the parent, and the browser places its children into the grid.

.card-list {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

1fr gives a column a share of the available space. Use gap to add space between rows and columns.

11. Adapt to different screens

Responsive design helps a page work on small and large screens. Flexible widths and media queries let styles change when the viewport is narrow.

.card-list {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

@media (max-width: 600px) {
  .card-list {
    grid-template-columns: 1fr;
  }
}

The media query applies its rules when the viewport is 600 pixels wide or less. Test layouts at different sizes as you build.

12. Interaction states and focus

Pseudo-classes style elements in a particular state. Use :hover for pointer hover and :focus-visible to make keyboard focus easy to see.

a:hover {
  text-decoration: underline;
}

button:focus-visible {
  outline: 3px solid royalblue;
  outline-offset: 3px;
}

Do not remove the browser's focus indicator unless you replace it with a clearly visible alternative.

13. Reuse values with CSS variables

Custom properties, often called CSS variables, store values you can reuse. Define them with two hyphens and read them with var().

:root {
  --brand-color: #2563eb;
  --card-padding: 20px;
}

.card {
  border-top: 4px solid var(--brand-color);
  padding: var(--card-padding);
}

Changing a value in one place updates every rule that uses that variable.

14. Debug and practice

If a style does not appear, check that the stylesheet path is correct, the selector matches the HTML, and each declaration ends with a semicolon. Also check for misspelled property names and missing braces.

Your practice project: create a small profile page and style its heading, paragraphs, links, and a card. Then try arranging a few cards with Grid, making them stack on a narrow screen, and adding a visible keyboard focus style.
