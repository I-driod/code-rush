JavaScript beginner's guide

Learn JavaScript

JavaScript adds behavior and interactivity to webpages. Learn the fundamentals, then use them to make a page respond to people.

In this guide, developers will learn about;

  • What JavaScript does
  • Add JavaScript to a page
  • Variables and values
  • Operators and comparisons
  • Make decisions
  • Repeat work with loops
  • Functions
  • Arrays
  • Objects
  • Work with the page
  • Respond to events
  • Handle form input
  • Asynchronous JavaScript
  • Debug and practice

1. What JavaScript does

HTML describes page content, CSS styles it, and JavaScript can make it interactive. JavaScript can respond to clicks, update text, validate input, and more.

JavaScript is case-sensitive, so message and Message are different names. Statements can be written on separate lines; semicolons are commonly used to mark their ends.

2. Add JavaScript to a page

Put your JavaScript in a separate .js file, then load it from the HTML page. The defer attribute runs the script after the HTML has been parsed.

<script src="script.js" defer></script>

For a quick experiment, you can also write JavaScript inside a <script> element. External files are easier to organize and reuse.

3. Variables and values

Variables give names to values. Use const by default, and use let when you need to assign a different value later.

const learnerName = "Alex";
let points = 0;
points = points + 10;

const isReady = true;

Common value types include strings (text), numbers, booleans (true or false), arrays, objects, and null. A const variable cannot be reassigned, though the contents of an object or array declared with const can still be changed.

4. Operators and comparisons

Operators perform calculations or compare values. Use === to check equality without converting between types, and !== to check inequality.

const total = 12 + 8;
const hasEnoughPoints = total >= 20;
const isDifferent = "5" !== 5;

Arithmetic operators include +, -, *, and /. Comparison expressions produce a boolean value.

5. Make decisions

Use an if statement to run code only when a condition is true. Add else for an alternative.

const score = 82;

if (score >= 70) {
  console.log("You passed!");
} else {
  console.log("Keep practicing.");
}

Use && when both conditions must be true, and || when either condition may be true.

6. Repeat work with loops

A loop runs a block of code repeatedly. A for loop is useful when you know how many times to repeat an action.

for (let count = 1; count <= 3; count++) {
  console.log("Practice round " + count);
}

The loop starts at 1, runs while the condition is true, and increases count after each round. Make sure a loop's condition eventually becomes false.

7. Create reusable functions

A function groups instructions so you can run them when needed. It can accept inputs called parameters and send a value back with return.

function greet(name) {
  return "Hello, " + name + "!";
}

const greeting = greet("Alex");
console.log(greeting);

An arrow function is another way to write a function:

const double = (number) => {
  return number * 2;
};

8. Store lists in arrays

An array holds an ordered list of values. Array positions start at index 0.

const courses = ["HTML", "CSS", "JavaScript"];
console.log(courses[0]); // HTML

courses.push("Accessibility");
console.log(courses.length); // 4

Use array methods such as push() to add an item. You can use for...of to visit each value:

for (const course of courses) {
  console.log(course);
}

9. Group related data in objects

An object stores related information as named properties. Read a property with dot notation.

const learner = {
  name: "Alex",
  points: 15
};

console.log(learner.name);
learner.points = 20;

Use an object when values describe one thing; use an array when you need an ordered list of things.

10. Find and update page elements

The browser represents a webpage as the Document Object Model (DOM). JavaScript can find elements and update their content.

<p id="message">Welcome!</p>
const message = document.querySelector("#message");
message.textContent = "Thanks for visiting!";

Use textContent for plain text. Avoid putting untrusted text into innerHTML, because it is interpreted as markup.

11. Respond to events

Events represent things that happen on a page, such as a button click. Use addEventListener() to run a function when an event occurs.

<button id="hello-button" type="button">Say hello</button>
<p id="message"></p>
const button = document.querySelector("#hello-button");
const message = document.querySelector("#message");

button.addEventListener("click", () => {
  message.textContent = "Hello!";
});

Event listeners keep behavior separate from the HTML and make the page respond to user actions.

12. Handle form input

Listen for a form's submit event to handle its values. Calling preventDefault() prevents the browser's default navigation while your code handles the example.

<form id="name-form">
  <label for="name">Your name</label>
  <input id="name" name="name" required>
  <button type="submit">Say hello</button>
</form>
<p id="greeting"></p>
const form = document.querySelector("#name-form");
const nameInput = document.querySelector("#name");
const greeting = document.querySelector("#greeting");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  greeting.textContent = "Hello, " + nameInput.value + "!";
});

Use built-in HTML validation, such as the required attribute, when it fits your form.

13. Asynchronous JavaScript

Some tasks, such as waiting for a timer or loading data, finish later. A Promise represents a result that may become available in the future. async and await help write asynchronous code clearly.

async function showMessage() {
  await new Promise((resolve) => setTimeout(resolve, 500));
  console.log("Half a second has passed.");
}

showMessage();

When using await, put it inside an async function. In real projects, handle errors from operations that can fail.

14. Debug and practice

Use console.log() to inspect values. If something does not work, read the browser's developer console for errors, check spelling and capitalization, and verify that the script loads after the page elements exist.

Your practice project: make a small quiz with a question, a text input, and a button. Use a function to check the answer, an if statement to choose a message, and the DOM to show the result.
