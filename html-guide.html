HTML beginner's guide

Learn HTML

HTML gives a webpage its structure. Learn the building blocks, then try changing the examples yourself.

In this guide, developers will learn about;

  • Elements and tags
  • A complete HTML page
  • Headings and text
  • Links and attributes
  • Images
  • Lists
  • Meaningful page structure
  • Tables
  • Forms
  • Accessibility basics
  • Comments and special characters
  • Practice project

1. Elements and tags

Most HTML elements have an opening tag, some content, and a closing tag. Tags are written inside angle brackets.

<p>This is a paragraph.</p>
<h1>This is a main heading.</h1>

The <p> element is for a paragraph. Use heading elements from <h1> to <h6> to organize sections.

Some elements are void elements: they do not wrap content and have no closing tag. Examples include <br> for a line break and <img> for an image.

2. A complete HTML page

Start a page with the document declaration, then give it a head for page information and a body for visible content.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, web!</h1>
  <p>I made this page with HTML.</p>
</body>
</html>

Save the file with an .html extension, such as index.html, then open it in a browser. The <title> appears in the browser tab; content inside <body> appears on the page.

3. Headings and text

Headings create an outline for your content. Start with a main <h1>, then use <h2> for major sections and <h3> for subsections. Choose heading levels by structure, not by their default size.

<h1>My Garden</h1>
<p>Welcome to my garden journal.</p>
<h2>What I'm growing</h2>
<p>This year I planted tomatoes and herbs.</p>

Use <strong> to indicate important text and <em> for emphasized text. Browsers usually display them in bold and italics, respectively.

4. Links and attributes

Attributes add information to an element. A link uses the href attribute to say where it goes.

<a href="about.html">Read about me</a>

Here, href is the attribute and about.html is its value. A relative path like this points to another file in your project. You can also link to a section on the same page:

<a href="#contact">Go to contact details</a>
...
<h2 id="contact">Contact details</h2>

Attribute values should be quoted. The id attribute identifies a unique element on the page.

5. Add images

The <img> element displays an image. Its src attribute points to the image file and its alt attribute describes the image.

<img src="garden.jpg" alt="Red tomatoes growing on a vine">

Keep the image file in your project and use the correct path. If an image is only decorative, use an empty alt value: alt="".

6. Make a list

Use an unordered list for items where order does not matter. Put each item inside an <li> element.

<ul>
  <li>Plan a page</li>
  <li>Write its HTML</li>
  <li>Open it in a browser</li>
</ul>

For steps that should be in order, use an ordered list:

<ol>
  <li>Create an HTML file</li>
  <li>Add some content</li>
  <li>Open the file in a browser</li>
</ol>

7. Structure content meaningfully

Semantic elements describe what their content means. Use <header> for introductory content, <main> for the primary content, and <footer> for closing information.

<header>
  <h1>My Recipe Book</h1>
</header>
<main>
  <article>
    <h2>Apple cake</h2>
    <p>A simple cake for autumn.</p>
  </article>
</main>
<footer>Written by Sam</footer>

Tip: Choose an element because of its meaning, not just how it looks. CSS can change how any element appears.

8. Show data in a table

Use a table for data that belongs in rows and columns, not to lay out an entire page. Table headings help explain each column.

<table>
  <caption>Weekly reading</caption>
  <tr>
    <th scope="col">Day</th>
    <th scope="col">Pages</th>
  </tr>
  <tr>
    <td>Monday</td>
    <td>12</td>
  </tr>
</table>

<th> marks a heading cell, while <td> marks an ordinary data cell.

9. Collect information with a form

Forms let people enter information. Connect each input to a visible label using matching for and id values.

<form>
  <label for="visitor-name">Your name</label>
  <input id="visitor-name" name="name" type="text">
  <button type="submit">Send</button>
</form>

The name attribute identifies the input's value when a form is submitted. A form needs a server or JavaScript to process submitted information.

10. Accessibility basics

Accessible HTML helps more people use your page, including people using keyboards or screen readers.

  • Give images useful alternative text with alt.
  • Use headings in a logical order to organize the page.
  • Use a real <button> for an action and an <a> for navigation.
  • Give form controls a descriptive, connected <label>.
  • Write link text that explains where the link goes.

11. Comments and special characters

Comments are notes in your HTML source. Browsers do not display them as page content.

<!-- This is a note for the people editing the file. -->

To show characters that HTML normally treats as markup, use character references:

&lt; displays <
&gt; displays >
&amp; displays &

12. Your practice project

Make a simple page about a hobby, favorite book, or pet. Try to include:

  • A page title and one main heading
  • Two sections with headings and paragraphs
  • A list and a link
  • An image with helpful alternative text
  • Semantic page structure using <header>, <main>, and <footer>

Save your file as index.html and open it in a browser to see your work.
